# MAD Lab Experiments

This repository contains a collection of 12 Android development experiments as part of the Mobile Application Development (MAD) Lab syllabus.

## Experiments List

1.  **[Exp-1](./Exp-1): Hello World** - Simple Android application with basic message display and screenshots.
2.  **[Exp-2](./Exp-2): Visiting Card** - UI design using various GUI components.
3.  **[Exp-3](./Exp-3): Calculator** - Basic arithmetic operations app.
4.  **[Exp-4](./Exp-4): Sign Up & Login** - Activity lifecycle and data validation.
5.  **[Exp-5](./Exp-5): Wallpaper Changer** - Managing system-wide settings.
6.  **[Exp-6](./Exp-6): Counter Application** - Multi-threading and background tasks.
7.  **[Exp-7](./Exp-7): JSON/XML Parser** - Data parsing and display.
8.  **[Exp-8](./Exp-8): Text-to-Speech** - Using native Android media engines.
9.  **[Exp-9](./Exp-9): Phone Dialer** - Inter-app communication using Intents.
10. **[Exp-10](./Exp-10): GPS Tracker** - Location-based services.
11. **[Exp-11](./Exp-11): SQLite DB** - Local data persistence.
12. **[Exp-12](./Exp-12): Notifications** - Sending system alerts.

## Requirements
- Android Studio Ladybug or later.
- Kotlin / Jetpack Compose.
- Android SDK 24+.
